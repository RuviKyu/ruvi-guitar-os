# Sampled instrument library

Ruvi v4.3 uses **FluidR3Mono GM 2.312** (5 December 2016), released under the MIT licence. Full copyright, acknowledgement and permission notices are in [FluidR3Mono-LICENSE.md](FluidR3Mono-LICENSE.md). No subscription, paid API or per-play royalty is required by that licence.

Copyright: Frank Wen (2000–2002, 2008), Michael Cowgill (2014–2016), Ethan Winer (2002, temple blocks) and Michael Schorsch (2016, drumline percussion). The original contributors' acknowledgements are retained in the licence file.

Pinned bank: https://raw.githubusercontent.com/musescore/MuseScore/v2.1.0/share/sound/FluidR3Mono_GM.sf3

Fallback CDN: https://cdn.jsdelivr.net/gh/musescore/MuseScore@v2.1.0/share/sound/FluidR3Mono_GM.sf3

SHA-256: `cfcd66d89e8386823400eca64934b14fbea7bf48ba1f00d21189af1262794ec2` (14,563,174 bytes). The browser verifies both size and hash, including cached downloads, before use. Source licence: https://github.com/musescore/MuseScore/blob/main/share/sound/FluidR3Mono_License.md

The first user-requested sampled playback downloads the bank and caches it on the device where storage is available. The application downloads no bank on initial page load or for YouTube playback. Basic synth remains an explicit, instant alternative if downloads, audio decoding or memory availability prevent sampled playback.

`fluidr3-map.json.gz` is compressed numeric SoundFont metadata and short PCM waveform data derived from this bank; it contains no executable code. It covers 128 GM programs, 35 percussion kits and 1,037 source samples. Very short Vorbis waveforms are represented as PCM because some browsers reject their short compressed streams. All other samples are sliced from the verified bank and decoded only as needed. Sample offsets, root tuning, velocity zones, sustain loops, envelopes, filtering, modulation and drum choke groups come from the bank. The room impulse is generated by Ruvi's own deterministic DSP.

Rebuild from repository root with `npm ci` then `npm run build:sample-map -- /path/to/FluidR3Mono_GM.sf3`; omit the path to download the pinned bank into ignored `.soundbank-cache/`. The extractor uses the pinned alphaTab development dependency, whose existing notices remain under `public/vendor/`; the application runtime is Ruvi's own Web Audio renderer. Decoded sample buffers are bounded at 192 MiB, decode concurrency is three, and inactive arrangement buffers are evicted before preparation. Active notes are limited to 80 logical voices.

Slides, bends and whammy curves alter sample playback rate continuously. Vibrato modulates pitch. Linked hammer-ons/pull-offs can reuse an active string waveform; other legato uses a softer attack. Palm mutes and dead notes shorten the envelope; ghost notes reduce level. Drum one-shots preserve natural tails. These are General MIDI samples rather than separately recorded performances for every guitar articulation, so timbre and realism remain limited by the library and the source arrangement.

MIDI exports retain instrument programs, velocity, timing and expressive pitch/controller data. Standard MIDI files do not embed this audio bank; an external player uses its own instrument sounds. Ruvi JSON exports retain the arrangement and techniques.
